# صور مجموعات دفتر جهات الاتصال

بطاقات 256×256 لكل مجموعة في دفتر «الدفتر الشامل»، بنفس التصميم والألوان
المتفق عليها. الغرض: إنهاء اللبس الذي حدث حين كانت كل الصور متشابهة.

## المجموعات والألوان

| المجموعة | اللون | الملف |
|---|---|---|
| ذكى منير | برتقالي `#F5751A` | `zaki-mounir.jpg` (256 فقط للمعاينة) |
| حارس | أزرق `#1D4ED7` | `hares.jpg` |
| الدولاب | بني `#8B4512` | `eldoulab.jpg` |
| قاعدة العملاء | أخضر بحدود ذهبية `#17A34A` / `#F2C94C` | `client-base.jpg` |
| **الافتراضي** — كل اسم آخر وأي جهة جديدة | رمادي داكن `#1F2933` | `default.jpg` |

الألوان الأربعة الأولى هي هوية المستخدم الثابتة. `default.jpg` يغطي كل ما
عداها (الأسماء الطبيعية، جهات أخرى، قاعدة العملاء عند عدم تمييزها، وأي اسم
جديد يُسجَّل لاحقًا) فلا حاجة لإضافة لون خامس.

الصور الجاهزة في `out/` — لا تحتاج تشغيل السكريبت إلا لتغيير نص أو لون.

> **الاستيراد في Google Contacts:** الحد 20 ميجا. كل كارت يحمل نسخة base64 من
> صورته، فصورة 256×256 (26 كيلو) × 1984 كارت = 26 ميجا ⇒ يُرفض. لذلك يجب
> تصغير الصور إلى 144×144 بجودة 72 (≈4 كيلو) قبل بناء ملف الاستيراد:
>
> ```bash
> for f in out/*.jpg; do n=$(basename "$f" .jpg)
>   convert "$f" -resize 144x144 -quality 72 -sampling-factor 4:2:0 "small/$n.jpg"
> done
> .venv/bin/python tools/contact-labels/build-vcf.py \
>     --src ./Diwan.vcf --labels ./small --out ./Diwan-11MB.vcf
> ```
>
> الناتج ≈ 11 ميجا — داخل الحد، والتمييز اللوني يبقى واضحًا في التطبيقات.

## الوضع المعتمد للاستيراد — 4 مجموعات فقط

المطلوب: يرى من بعيد **لون** المجموعة فيعرف مصدر المكالمة، بينما تظل صور
الناس الحقيقية ظاهرة لمن لا ينتمي لمجموعة ملوّنة.

| المجموعة | اللون | صورة |
|---|---|---|
| ذكى منير | 🟠 برتقالي `#F5751A` | `zaki-mounir.jpg` — 38 كارت |
| حارس | 🔵 أزرق `#1D4ED7` | `hares.jpg` — 33 كارت |
| الدولاب | 🟤 بني `#8B4512` | `eldoulab.jpg` — 59 كارت |
| قاعدة العملاء | 🟢 أخضر بحدود ذهبية | `client-base.jpg` — 86 كارت |
| **الباقي** (الأسماء الطبيعية / جهات أخرى / أي اسم جديد) | **بلا صورة** | — 1768 كارت |

```bash
# 1) تصغير الصور الأربع (الحد 20 ميجا على Google Contacts)
for n in zaki-mounir hares eldoulab client-base; do
  convert "tools/contact-labels/out/$n.jpg" \
      -resize 144x144 -quality 72 -sampling-factor 4:2:0 \
      "tools/contact-labels/small/$n.jpg"
done

# 2) بناء الملف — المجموعات الأربع فقط تأخذ صورة
python3 tools/contact-labels/build-vcf.py \
    --src ./Diwan.vcf \
    --labels ./tools/contact-labels/small \
    --default-no-photo \
    --out ./Diwan-4-groups.vcf
```

الناتج: **216 كارت بصورة + 1768 بلا صورة**, حجم ≈ 1.85 ميجا, وكل الصور
JPEG سليمة 144×144 بمعدل 4.4 كيلو.

> `--default-no-photo` هو الوضع الافتراضي المطلوب. الصور الخمس في `out/`
> تبقى مرجعًا للهوية اللونية؛ `default.jpg` لم يعد يُستخدم في الاستيراد.

## إعادة التوليد

PIL في بيئة التشغيل مبني بلا `raqm`، فرسم النص العربي مباشرةً ينتج حروفًا
منفصلة ومقلوبة. لذلك يشكّل السكريبت النص بـ HarfBuzz ثم يرسم كل glyph
بـ FreeType — لا `arabic_reshaper` ولا `bidi`.

```bash
python3 -m venv .venv
.venv/bin/pip install Pillow uharfbuzz freetype-py fonttools brotli
.venv/bin/python tools/contact-labels/make-labels.py --out ./labels
```

الخط يُستخرج من `assets/fonts/cairo-arabic-900-normal.woff2` إلى مجلد مؤقت؛
لا يُكتب أي ملف خط داخل المستودع.

## الاستخدام في الهاتف

1. انقل ملفات `out/*.jpg` إلى الهاتف.
2. في جهات الاتصال: اختر المجموعة ← تعيين صورة.
3. الاسم المعروض داخل الصورة هو اسم المجموعة؛ لا حاجة لتعديله.

> الصور لا تحتوي على أي بيانات عميل، فهي آمنة للتخزين في المستودع.
