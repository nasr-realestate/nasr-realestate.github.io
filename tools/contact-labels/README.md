# صور مجموعات دفتر جهات الاتصال

بطاقات 256×256 لكل مجموعة في دفتر «الدفتر الشامل»، بنفس التصميم والألوان
المتفق عليها. الغرض: إنهاء اللبس الذي حدث حين كانت كل الصور متشابهة.

## المجموعات والألوان

| المجموعة | اللون | الملف |
|---|---|---|
| ذكى منير | برتقالي `#F5751A` | `zaki-mounir.jpg` |
| حارس | أزرق `#1D4ED7` | `hares.jpg` |
| الدولاب | بني `#8B4512` | `eldoulab.jpg` |
| قاعدة العملاء | أخضر بحدود ذهبية `#17A34A` / `#F2C94C` | `client-base.jpg` |
| **الافتراضي** — كل اسم آخر وأي جهة جديدة | رمادي داكن `#1F2933` | `default.jpg` |

الألوان الأربعة الأولى هي هوية المستخدم الثابتة. `default.jpg` يغطي كل ما
عداها (الأسماء الطبيعية، جهات أخرى، قاعدة العملاء عند عدم تمييزها، وأي اسم
جديد يُسجَّل لاحقًا) فلا حاجة لإضافة لون خامس.

الصور الجاهزة في `out/` — لا تحتاج تشغيل السكريبت إلا لتغيير نص أو لون.

## إعادة التوليد

PIL في بيئة التشغيل مبني بلا `raqm`، فرسم النص العربي مباشرةً ينتج حروفًا
منفصلة ومقلوبة. لذلك يشكّل السكريبت النص بـ HarfBuzz ثم يرسم كل glyph
بـ FreeType — لا `arabic_reshaper` ولا `bidi`.

```bash
python3 -m venv .venv
.venv/bin/pip install Pillow uharfbuzz freetype-py fonttools brotli
.venv/bin/python tools/contact-labels/make-labels.py --out ./labels
```

الخط يُستخرج من `assets/fonts/cairo-arabic-900-normal.woff2` إلى مجلد مؤقت؛
لا يُكتب أي ملف خط داخل المستودع.

## الاستخدام في الهاتف

1. انقل ملفات `out/*.jpg` إلى الهاتف.
2. في جهات الاتصال: اختر المجموعة ← تعيين صورة.
3. الاسم المعروض داخل الصورة هو اسم المجموعة؛ لا حاجة لتعديله.

> الصور لا تحتوي على أي بيانات عميل، فهي آمنة للتخزين في المستودع.
