# ⚠️ إصلاحان موثّقان (2026-10-16):
#
#   1) ترتيب القواعد: كان `Disallow: /*.json$` مكتوبًا **قبل**
#      `Allow: /ai-feed.json`. الزواحف التي تعتمد أول قاعدة مطابقة
#      (first-match) كانت تحجب ai-feed.json — أي أن الملف الذي بُني
#      ليقرأه الذكاء الاصطناعي كان محجوبًا بقاعدة عامة. الحل: كل
#      قواعد Allow مكتوبة الآن **قبل** قواعد Disallow داخل نفس الكتلة.
#
#   2) `Disallow: /*.json$` كان يحجب أيضًا `/manifest.json` و
#      `/site.webmanifest` — وهي ملفات يحتاجها Google لاعتبار الموقع
#      تطبيقًا قابلًا للتثبيت (PWA). لا يوجد أي JSON داخلي منشور في
#      الموقع أصلًا: كل ما يُنشر إما بيانات آليّة مقصودة أو مانيفست.
#      لذلك حُذفت القاعدة، ولم يبقَ سوى حجب ملفات المصدر والبناء.
